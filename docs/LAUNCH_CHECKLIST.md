## Before accepting real public enquiries

- [ ] Verify info@promomerch.ca, phone routing and the responsible enquiry owner.
- [ ] Configure a transactional provider and reliable notification queue/retries; test real inbox receipt in both languages.
- [ ] Establish authorized operator access to stored requests and private artwork.
- [ ] Confirm Facility Unlimited Corp. or explicitly approve the correct legal seller; review privacy/terms and consent wording for actual operations.
- [ ] Decide retention, backup/recovery, upload review and orphan reconciliation policies.
- [ ] Validate supplier models, decoration, pricing/quantity conventions, available imagery and any published delivery claims.
- [ ] Review the reconstructed logo contours and French descriptor as part of the design review.
- [ ] Complete remaining accessibility/performance checks on the selected public runtime.
- [ ] Confirm the final host. WHC requires adapters for the current Workers/D1/R2 integration.

## Authorized public cutover, later

- [ ] Obtain the specific public launch/domain/migration instruction and verify domain access.
- [ ] Set the correct live origin and publicLaunch policy; verify canonical, language alternatives, sitemap and robots on the public host.
- [ ] Test HTTPS, actual HTTP status/redirect behavior, all live routes, icons, forms and private-file isolation.
- [ ] Map and apply only reviewed legacy redirects; retain old mail/contact continuity.
- [ ] Connect approved analytics/search tools and verify actual submission/indexing states.
- [ ] Perform a post-launch quote-to-inbox check and verify rollback readiness.
- [ ] Send announcements only when their audience and content are explicitly authorized.
